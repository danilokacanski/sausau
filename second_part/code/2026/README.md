# Machine Learning Course - 2026

This folder contains code examples from the computer lab sessions for the 2025/2026 academic year.

The examples follow the machine learning part of the course and cover core topics such as data preprocessing, train/validation/test splitting, 
linear models, classification and regression, regularization, evaluation metrics, generalization, cross-validation, 
KNN, K-Means, SVM, decision trees, ensemble methods, hyperparameter tuning and basic model deployment.

The materials are intended to support the lab exercises and provide simple practical examples that students can use while following the course topics.
